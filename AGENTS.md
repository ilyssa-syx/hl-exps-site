# Repository rules

- Keep this repository self-contained. Runtime code must not depend on a sibling checkout.
- Keep large generated assets out of Git; publish them to object storage and reference them by URL.
- `configs/examples/` is the editable source of truth for examples.
- `public/data/manifest.json` is generated by `npm run export`; do not edit it by hand.
- Prefer reusable converters under `scripts/` over one-off checked-in utilities.
- Do not commit, push, or change GitHub Pages settings unless the user explicitly asks.
